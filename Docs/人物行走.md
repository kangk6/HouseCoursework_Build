# 人物行走

当前采用 CMU 07_01 真人行走数据，经目标人物骨架重定向后驱动现有 Harper 人物。保留待机模型和衣着，替换原来数学姿态生成的快步素材。动作来源、校准方法与重建步骤见 [Tools/ResidentGait](../Tools/ResidentGait/README.md)。

行走循环为66个60fps采样关键帧，约1.083秒。离线校准脚掌翻转、脚跟和前掌接触、骨盆高度以及头部朝向，保持携带物隐藏。正常移动速度为140厘米/秒，以源动作约135.62厘米/秒的步幅匹配播放速度；起停沿用待机混合，转弯继续提前减速。

移动胶囊底部和地面通常有约2.15厘米间隙，人物网格向下补偿这一高度，避免整个人物悬起。验收补充了人物网格原点与地面间距检查，并将移动中的骨盆起伏要求收紧到8厘米以内。

原地预览用同一人物、同一平整测试面比较新旧动作；随后在打包程序中回归完整撤离、上下楼玩家路线、受阻恢复与复位。原地预览是渲染采样，不代表前台帧率。当前接触校准针对这段动作和平地，未加入运行时通用足部IK或独立转身动画。

本轮新增 A_ResidentWalk 与 BS_ResidentWalk 两个资源，团队增量包位于 D:/HouseCoursework_TeamAssets/v0.23.5-mocap-walk。协作组员需要拉取源码并导入该包，才能与本机一致。原运行包的资源容器不覆盖，新增独立的 ResidentMocap 容器，回滚时可移除。
