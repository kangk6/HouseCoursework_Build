# 人物行走衔接

沿用原有 Harper 快步行走与待机动画，本轮调整实际移动和动画之间的衔接，不新增报警反应或集合动作。

- 连续直线上的中间路径点不再按距离逐点刹车，临近明显转角才减速，最终集合点单独减速。
- 路径点使用小范围到达和近距离通过判定，避免一次移动跨过目标后反向追逐目标点。通过判定保留高度检查，不允许直接跳过远处路径点。
- 最高速度从180降至160厘米/秒，加速与刹车放缓，身体按每秒180度转向；尚未对准方向时限制迈步，减少身体侧向滑移。
- 将实际速度映射到原有170厘米/秒动画轴，行走播放速度按160/170匹配；待机恢复正常播放，避免减小混合步幅的同时又重复按速度放慢动画。

仍使用 CharacterMovement 碰撞、原有撤离路线和避让逻辑，不增加瞬移。现有动作素材、足部接触和转身素材仍有限，本轮未增加足部IK、独立转身动画或新骨骼资源。

本机离屏验收目录：Saved/Acceptance/ResidentWalk20261104/publish。可选 HouseWalkFrames 参数保存客厅与室外行走截图，作为姿态检查资料；稀疏截图不代表前台流畅度认证。资源包保持不变。
