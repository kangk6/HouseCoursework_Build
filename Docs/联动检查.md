# 时间、天气与照明联动检查

2026年10月25日，基于v0.20.1检查已有功能之间的状态衔接。修改前源码标记为 `联动打磨前-20261025`。

## 修正内容

手动跳转时间时，太阳位置平滑过渡，而阅读补光和起夜照明原先立即使用目标时刻的太阳高度。因此画面尚未天黑，照明就可能先切换；从夜间跳到白天也有相反问题。

现在两者使用实际渲染太阳的高度。阅读补光同时考虑已有天气采光系数；起夜照明仍在太阳高度低于6度时启用。时钟目标值、太阳运动方式、天气随机规则和光伏算法保持原有含义。没有增加界面说明、按钮或资源包。

## 验证方式

```powershell
.\Tools\check_clock_foundation.ps1 -Mode linkage -Height 1080
.\Tools\check_clock_foundation.ps1 -Mode linkage -Height 720
```

专项检查在中午与午夜间跳转，逐帧对照实际太阳高度、阅读补光目标和起夜判断；检查同一中午由晴转阴时补光增强、光伏下降，以及开启电脑、两台电视和冰箱后的供用电平衡。

另有8种组合：固定／流动时间、手动／自动天气、阅读／起夜照明。每种依次经过帮助面板、火警、火警中的暂停、结束演练与恢复运行，核对天气随机数状态、时钟、家电开关、累计能量、照明模式和单灯手动优先设置。被火警阻止的天气操作不应消耗随机数；恢复运行不应补算暂停期间的时间或用电。

维护机证据目录为 `Saved/Acceptance/EnvironmentLinkage`，Before保留修正前失败记录。另回归时钟、圆盘控件、光伏、家电天气、智慧照明、演练恢复，并运行完整自然昼夜采样及晨昏亮度变化检查。

这些检查使用真实运行程序中的控制器、灯光与状态，场景位置由脚本设置，不能代替所有位置下的人工游玩，也不作为帧率证明。未修改本轮无关的家具交互，不重复执行上一版131个部件的两轮开关检查。
