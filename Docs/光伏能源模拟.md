# 光伏与照明能源模拟

## 对应要求与操作

绿色方向要求至少实现一项光伏发电、雨水回用、能耗监测或节能控制等功能，并展示资源或能源流动。本功能以屋顶发电、照明消耗、电网补电和余电输出构成可独立演示的能源过程。

界面累计标签“太阳能供电”“电网供电”“余电上网”分别对应算法中的光伏自用、电网取电、余电输出，单位“度”等于kWh。配电节点把两种电源与照明分支分开，不表示灯具向外发电。

Tab → 绿色。默认正午查看发电和余电输出；去智慧页开关或调暗照明，再回绿色页查看负荷变化。舒适页把时间改到夜间并应用，观察光伏归零和电网补电；改到日出附近，观察少量光伏与电网共同供电。固定时间后仍可观察累计电量。

## 配置与计算

六块光伏板，单块170×110 cm、360 W，总计2160 Wp。运行时对住宅屋顶执行复杂碰撞射线，取实际位置与法线安装，两排三列。朝向相同的板分别计算后求和。三个实例化网格组绘制边框、板面和电池片分隔线，关闭交互碰撞；不改动住宅源地图。

发电使用实际渲染太阳方向的反向单位向量s，板面朝外单位法线n。向量均为世界坐标，h=s.z。h≤0时功率严格为零。h>0时：

```text
直射法向辐照度 DNI = 900 × smoothstep(0, 0.25, h) W/m²
板面散射辐照度 = 100 × h × (1 + clamp(n.z,-1,1)) / 2 W/m²
板面总辐照度 G = DNI × max(dot(s,n),0) + 板面散射辐照度
单板交流功率 = min(360, 360 × G / 1000 × 0.90) W
```

900与100为晴天教学参数，不是实测气象数据；1000 W/m²为额定功率参考辐照度。0.90合并逆变、线路等损失，不再重复乘组件转换效率。正面垂直日照、太阳在天顶的测试条件下，360 W板输出324 W。

功率与有效板面辐照度成比例的基本思路参考[Sandia PVPMC 的 PVWatts 模型说明](https://pvpmc.sandia.gov/modeling-guide/2-dc-module-iv/point-value-models/pvwatts/)。本实现不是完整PVWatts，没有其气象和电池温度模型，也未校准到真实地点。

沿用现有太阳示例轨迹：约6点日出、18点日落，最大高度65°。手动跳时后功率跟随渲染太阳平滑过渡，不能直接把UE光源Intensity当作W/m²。未加入季节、云层、地面反射、局部遮阴、温度变化、积灰变化和组件老化。背向太阳时直射为零，天空散射仍可能非零。

照明沿用九回路的配置额定功率48、32、36、24、12、12、12、24、16 W，合计216 W。手动状态按开关与亮度计算；智慧状态按实体灯具额定功率加权求和。渲染补光不另算电器。LED亮度与功率采用线性近似，待机功率忽略；不包含空调、冰箱等其他家电。

## 能源收支

```text
光伏自用 = min(光伏发电, 照明用电)
电网取电 = max(照明用电 - 光伏发电, 0)
余电输出 = max(光伏发电 - 照明用电, 0)
光伏发电 + 电网取电 = 照明用电 + 余电输出
```

假设电网可用且允许余电并网，不模拟电网故障、交流电路、限发或蓄电池。光伏装机大于照明负荷，白天较多余电输出属于预期结果，不为演示平衡而缩小额定功率或增大照明用电。

光伏自用累计表示相同照明需求下减少的电网取电量。余电输出单列，不重复计算为住宅自用，不推算电费或碳排放。

## 累计规则

电量增量(kWh)=当前功率(W)×模拟运行秒数/3600000。独立记录能源运行时长，每帧用实际DeltaSeconds按1440/DayMinutes转换：默认DayMinutes=24，因此现实1秒=模拟60秒；连续全天验收使用已有6分钟/天速度。

固定太阳时间也累计，表示同一日照条件维持运行；跳时接口不产生经过时长。暂停、帮助、时间编辑、火警演练和启动遮罩期间暂停统计，恢复后不补账。绿色页及普通漫游继续累计。演练期间功率读数仍反映实时场景，暂停的是累计。场景与累计均不修改正常灯光存档；重启后从新一次模拟开始。
