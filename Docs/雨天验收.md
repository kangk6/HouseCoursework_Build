# 雨天接入

入口：Tab → 舒适 → 天气 → 雨天。保留原来三种天气的位置，右侧增加雨天；不增加第二套天气面板、降雨滑条或提示段落。

白天室内亮度问题的后续修正与对照检查见[雨天室内采光](雨天室内采光.md)。

自动过程为晴、多云、阴、雨之间的相邻转移，先转阴再下雨，雨停先回阴。切换沿用10秒平滑过渡；雨天影响已有太阳光、散射光、光伏与阅读补光。系数和转移概率见[家电与天气](家电与天气.md)。

## 表现与边界

雨丝使用现有已打包基础网格与材质，在观察者周围生成竖直降雨。每列通过场景碰撞射线找到最上方遮挡，雨丝在遮挡之上停止。观察者上方有屋顶时，雨声平滑降低；声音为运行时合成。雨停后隐藏雨丝并停止逐滴更新，声音渐退。

固定时刻仍播放降雨；暂停菜单冻结雨滴运动并静音。火警保持当前天气，不切换成晴天或夜间，雨效继续播放。关闭游戏后天气按正常启动规则重置，不写入灯光存档。

这一版没有风吹斜雨、积水、湿地面、屋檐水流、雷暴或降雨导致的通风变化。遮雨依赖场景的可见性碰撞；九个既有房间的屋顶探测已列入专项检查，不能据此保证所有装饰性棚顶均具备正确碰撞。
