# 日月星空

太阳、月亮和星空使用现有的24小时时钟与天气，无新增按钮。太阳在白天移动，日出日落偏暖；夜晚显示简化满月与稀疏星点，星点有轻微亮度变化。固定时间停止天体位置变化，云与微弱闪烁仍是环境动画。时间圆盘的插值、暂停和火警冻结规则继续沿用。

## 连接方式

- 只复制引擎天空材质，不改住宅地图或引擎原件。保留旧天空的背景、云纹理与云遮罩；新日月星点直接受同一云遮罩影响。晴天局部薄云也可能遮住月亮的一部分，阴雨天气另有整体衰减，雨天完全隐去天体和星点。
- 关闭原天空日轮、旧星点和大气自带日轮，避免重复。新太阳的方向直接取实际日光方向；不改变原有太阳强度和光伏计算。
- 新月光替代旧固定夜间方向光，方向与可见月亮一致；满月最高强度为0.12，随月亮高度和天气减弱。保留原室内低强度辅助照明与家用灯控制。
- 星点按立方体六面分布，再在球面上计算距离，避免经纬投影极点聚集与拉线；位置由方向和时刻决定，走动不产生近景视差。
- 黎明和黄昏用短时暮光背景衔接旧天空的日夜分支，避免日出临界点背景同时归零。暮光不额外创建方向光。

## 简化

采用固定满月，月亮与太阳相对运行；不计算真实地点、日期、月相、真实星座或天文轨道。月面为程序化明暗与环形坑，太阳视直径约0.64度、月亮约1.0度，月亮适当放大便于演示。星点闪烁只是幅度很小的动画。云层沿用原住宅的简化天空云，不是体积云模拟。露出天空的窗口可以看见天体，但窗帘、房屋、树木与周边建筑仍会遮挡。
