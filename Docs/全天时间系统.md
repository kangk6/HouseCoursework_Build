# 全天时间系统

当前版本使用24小时圆盘。每次进入从中午12:00开始，默认现实24分钟对应一天；固定时间只停止昼夜变化。

## 操作

Tab → 舒适 → 昼夜时间。拖动或点击圆周选择时间，方向键微调15分钟，点击“应用”确认。“固定时间”与所选时刻一并应用。退出或切换页面取消未应用的编辑。主页面不再放时段预设、回到正午、观察点跳转或流速按钮。

时间页、帮助页、暂停菜单以及火警演练期间暂缓时钟推进，不改流动/固定模式。自然通风页及其他控制页不暂停时钟。自然经过午夜增加天数，手动跳时不增加天数或累计模拟时长。日照继续服务于智慧照明，照明存档与窗户状态保持独立。

## 启动处理

原先模块每0.5秒检查一次是否需要挂载住宅HUD，首帧可能先显示原夜景。现在在世界初始化、玩家建立前设置HUD类，原定时检查只作兜底。使用真正的手动镜头遮挡和覆盖界面的黑色层，等待灯具初始化、正午环境、天空捕获和曝光就绪后再淡入。零时长的StartCameraFade不再用于保持黑屏。

## 界面精简

- 智慧：房间开关、亮度、全屋开关、两种生活场景；再次点击选中场景退出。
- 安全：按状态显示“启动演练”“中止演练”或“结束演练”中的一个，演练中保留路线入口和人员状态。
- 绿色：照明功率、估算电量、方案对比与流向图。完整算法假设放在文档，不在界面常驻显示。
- 通风：房间窗户开关、气流显示和当前换气状态；删除复位、跳转观察点和教学段落。
- 帮助、暂停与地图：删去重复说明，操作方法集中放在帮助；普通控制页底部只保留一个返回入口。

字体沿用既有龙藏标题、文楷正文与轻字重数字；添加统一遮罩提高亮场景中的可读性。没有改模型、材质、蓝图或资源包。

启动检查从首个HUD tick开始，按帧读取画面，检查遮挡期像素及首次显示时的太阳状态；不以启动几秒后的单张正午截图代替检查。UI采用实际Slate指针事件，属于合成输入，不声称人工键鼠重放。像素读取增加开销，不作为正常运行帧率基准。
