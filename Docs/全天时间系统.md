# 全天时间系统

本次完成时间基础，不包含圆盘界面、光伏或储能。启动时为第1天中午12:00，默认流动，现实24分钟对应场景一天。

## 操作

Tab → 舒适 → 日照采光：

- 原滑块扩展到00:00～23:59，方向键每次调节15分钟，可以跨午夜。
- “时间流动”与“固定当前时间”切换昼夜推进方式。固定时间不暂停场景中的人物、家具、灯光和通风。
- 一天可对应现实6、24或60分钟。
- “回到正午”只回到12:00，不改变流动/固定模式。
- 打开日照页、帮助页或暂停菜单时暂缓推进时间，关闭后按原模式继续。自然通风页和其他控制页不暂停时钟。
- 火灾演练期间暂缓推进时间，禁止改时刻和模式，演练结束后按原模式继续。演练计时、烟雾和人物疏散继续使用原来的场景时间，不受昼夜流速影响。

## 接入方式

`FCourseworkClock`保存当前时刻、天数、流速、是否流动，以及自然经过的模拟时长。HUD先推进时钟，再更新环境目标、火警和智慧照明；时间控制入口仍复用原接口，避免出现两套时间。

手动调时不增加天数或累计模拟时长。自然经过午夜才增加天数。现有能源页仍是静态的“当前照明功率×选定时长”估算，未改为累计电表。

环境渲染继续平滑跟随目标时刻，按圆周最短距离过渡，避免23:59到00:00时扫过正午。启动时直接设置正午环境，等待原灯具与夜间补光初始化后捕获环境状态，并淡入场景。夜间保留已经调整过的原场景天空、曝光与环境补光。

智慧照明继续读取当前模拟太阳高度：就寝起夜在天黑后启用引路，天亮后停止引路；阅读助手随日照补光。日照切换不覆盖房间灯光存档，不重置门窗。此次不改变火警、通风和灯具本身的规则。

时间与太阳轨迹仍是教学示例，未接真实经纬度、日期或气象。模式、流速与天数只保留到本次运行结束，下次重新从12:00开始。
