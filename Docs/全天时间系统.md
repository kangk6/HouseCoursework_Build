# 全天时间系统

当前版本使用24小时圆盘。每次进入从中午12:00开始，默认现实24分钟对应一天；固定时间只停止昼夜变化。

## 操作

Tab → 舒适 → 昼夜时间。拖动或点击圆周选择时间，方向键微调15分钟，点击“应用”确认。“固定时间”与所选时刻一并应用。退出或切换页面取消未应用的编辑。主页面不再放时段预设、回到正午、观察点跳转或流速按钮。

时间页、帮助页、暂停菜单以及火警演练期间暂缓时钟推进，不改流动/固定模式。自然通风页及其他控制页不暂停时钟。自然经过午夜增加天数，手动跳时不增加天数或累计模拟时长。日照继续服务于智慧照明，照明存档与窗户状态保持独立。

火警演练开始时暂存智慧照明场景、单灯手动接管和整房手动优先选择。结束或中止后恢复这些选择，并按当前位置重新判断阅读占用和引路照明；已经过期的感应延时不回放。通风展示在演练期间隐藏，结束后恢复原来的显示选择，已开窗扇不被自动关闭。关闭程序时仅清理，不重启智慧照明。

手动关闭的灯仍记住关闭前的非零亮度。演练期间新作的整房照明调整优先于演练前的自动场景或旧单灯接管，结束后不覆盖这次调整。

## 启动处理

原先模块每0.5秒检查一次是否需要挂载住宅HUD，首帧可能先显示原夜景。现在在世界初始化、玩家建立前设置HUD类，原定时检查只作兜底。使用真正的手动镜头遮挡和覆盖界面的黑色层，等待灯具初始化、正午环境、天空捕获和曝光就绪后再淡入。零时长的StartCameraFade不再用于保持黑屏。

日夜使用同一个动态天空光，避免在旧静态天空光和动态天空光之间反复切换渲染路径。日出、日落时，大气天空辐亮度、旧天空球的颜色与星光、月光及两层夜雾密度一起渐变。深夜保留原天空材质参数、月光、雾、曝光及局部环境灯；原静态天空光及源材质不改写，退出环境系统时完整恢复。不是地理或气象级的天空模型。

夜雾还同时渐变最大不透明度：仅降低密度时，远处天空仍可能迅速达到雾的不透明上限，形成蓝色接缝。太阳在夜间保留0.00001单位的渲染占位强度，避免UE在零强度时移除大气主光源；验收读取实际强度，以不高于0.00002判定无可见太阳照明，不将占位值伪报为零。月光不再竞争大气主光源槽位，退出环境系统时恢复其原设置。

## 界面精简

- 智慧：房间开关、亮度、全屋开关、两种生活场景；再次点击选中场景退出。
- 安全：按状态显示“启动演练”“中止演练”或“结束演练”中的一个，演练中保留路线入口和人员状态。
- 绿色：照明功率、估算电量、方案对比与流向图。完整算法假设放在文档，不在界面常驻显示。
- 通风：房间窗户开关、气流显示和当前换气状态；删除复位、跳转观察点和教学段落。
- 帮助、暂停与地图：删去重复说明，操作方法集中放在帮助；普通控制页底部只保留一个返回入口。

字体沿用既有龙藏标题、文楷正文与轻字重数字；添加统一遮罩提高亮场景中的可读性。没有改模型、材质、蓝图或资源包。

## 验证

独立程序使用D3D12。720p首轮通过启动逐帧检查及39项圆盘/简化界面检查；随后调整文字与对比度，1080p复验相同交互。

1080p检查覆盖：启动遮挡、圆盘预览/确认/取消、跨午夜拖动、固定/流动、火警期间锁定、各页必要控件、时间核心、智慧照明、日照、通风、能源和页面切换。Game和Editor均编译通过。详细报告与截图在维护机`Saved/Acceptance/DialRefinement`，测试使用独立照明配置。

启动检查从首个HUD tick开始，按帧读取画面，检查遮挡期像素及首次显示时的太阳状态；不以启动几秒后的单张正午截图代替检查。UI采用实际Slate指针事件，属于合成输入，不声称人工键鼠重放。像素读取增加开销，不作为正常运行帧率基准。

复现：

```powershell
.\Tools\check_clock_foundation.ps1 -GameRoot "自己的独立程序目录" -Mode startup -Height 1080
.\Tools\check_clock_foundation.ps1 -GameRoot "自己的独立程序目录" -Mode dial -Height 1080
```

时钟和示例太阳轨迹未绑定真实地理、季节或天气。没有接入光伏、储能或动态累计电表。

### 连续昼夜与演练恢复检查

新增`day_cycle`检查：从默认正午开始，不调用跳时接口、不改变世界时间倍率，临时采用已有的现实6分钟/天速度，连续渲染到第二天正午。记录全部24个时段、跨午夜天数、太阳与时钟的偏差、阅读台灯真实光源输出，以及手动接管是否经过日落、午夜、日出仍然保持。固定书房视点读取画面亮度并保存关键帧，不能据此推断全屋每个视点或实际帧率。

`drill_restore`覆盖12组白天/夜晚、固定/流动、手动/就寝起夜/阅读助手组合，分别在烟感报警前后中止演练，检查时间、智慧场景、单灯及整房手动优先、窗扇、气流显示和住户恢复。正常完成另用真实CharacterMovement疏散测试，合成输入步行到集合点，住户沿原路线撤离，不以直接设置“已集合”替代。

```powershell
.\Tools\check_clock_foundation.ps1 -Mode day_cycle -Height 1080
python .\Tools\check_day_cycle_samples.py "验收目录\day_cycle_1080.json"
.\Tools\check_clock_foundation.ps1 -Mode drill_restore -Height 1080
.\Tools\check_clock_foundation.ps1 -Mode evacuation -Height 1080 -ExtraArguments '-HouseEvacHour=12','-HouseEvacFlow'
.\Tools\check_clock_foundation.ps1 -Mode evacuation_upper -Height 1080 -ExtraArguments '-HouseEvacHour=21'
```

本轮维护机证据目录为`Saved/Acceptance/EnvironmentIntegration`。正式默认速度保持24分钟/天；测试不读取或覆盖用户的灯光存档。以上属于测试脚本驱动的运行验收，未使用人工键鼠重放。
