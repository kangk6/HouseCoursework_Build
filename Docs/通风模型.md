# 通风计算与效果打磨

老师的舒适评分要求支持参数变化或方案对比；采光通风示例要求表现空气进入、流动与排出的路径，并通过开关门窗观察差别。本次沿用现有入口和窗户，不增加界面标签或新场景。

## 计算改动

原来的开口流量正比于压差，房门接近完全打开才参与计算。本次改为相对开口模型：`q = C × sign(Δp) × sqrt(abs(Δp))`。零压差附近用小范围线性过渡，避免导数发散；使用双精度、带回溯的 Newton 联立求解，并核对每个房间的净流量残差。完全封闭、没有室外压力边界的房间组单独固定参考压力，避免矩阵奇异。

参考的是 [EnergyPlus 气流网络工程说明](https://bigladdersoftware.com/epx/docs/22-2/engineering-reference/airflownetwork-model.html)中以节点压力和连接流量计算多区域通风、检查质量守恒的思路，以及开口速度随压差平方根变化的关系。这里没有接入 EnergyPlus，也不是复现其完整算法或得到其验证的模型。

滑动窗的有效开口跟随实际动画位移比例；转轴窗使用开启角度的正弦近似，保留原来小型上悬窗的满开面积折减。房门从小角度开启就逐步参与计算，不再到95%才突然连通。动画中分档更新网络，更新频率上限约5次每秒，完全开、完全关状态另行识别。

## 画面与声音

- 窗边风声由平滑后的相对交换量驱动，保留空间衰减。
- 窗帘与附近叶片使用同一开口的交换量；薄纱和厚帘采用不同的摆幅。窗帘方向随进出风方向变化，关窗后渐停。
- 贯通流线的速度和数量随路径分配到的相对流量变化。仍保留碰撞检查与观察遮挡，不用流线穿过墙壁表达连通。
- 单侧开窗的净贯通流量可以为零，但仍保留弱局部交换。该交换采用小幅面积经验项，单独驱动窗边反馈，不计入守恒流量，不代表已模拟真实湍流。

## 范围与限制

仍是固定室外风向下的相对压力网络，未校准风速、风压系数、开口流量系数和房间容积。不会输出 Pa、m/s、m³/h 或真实换气次数。尚未加入温差浮力、门窗缝隙渗透、风阵变化、室内温湿度、完整三维速度场和布料物理。路径绕开家具只是可视化布线，不是计算了家具后的涡流。声音与摆幅的映射属于视觉听觉设计，不是实测关系。

体验对比可选二楼书柜旁窗户与走廊窗：两处打开，先关书房门，再开门观察贯通；另把书房另一面窗打开，比较房间内部对流。比较跨房间方案时，保持侧室门和其他窗户状态相同，避免混入另一条通路。
