# 雨效与室外湿润

入口仍是 Tab → 舒适 → 天气 → 雨天，不增加控制项。

## 这一轮的变化

- 雨丝从不透明细方块改为柔边透明片，靠近镜头渐隐，远近宽度、长度和速度有区别；沿现有室外负X风向轻微斜落。
- 遮挡射线与斜落轨迹一致，遇到最上方地面、屋顶或其他阻挡后停止。附近硬地面和屋顶出现少量短暂溅水，草地、人物、家具不产生硬地面溅水。
- 沥青、车道、铺地和屋面逐渐变深、增强反光。原纹理、法线、UV和金属度保留，室内地板、窗帘与草地不套湿润材质。
- 连续中雨约30秒达到满湿，晴天约3分钟恢复干燥。停止下雨后不会立刻把地面变干；恢复干燥时撤回动态材质，恢复原材质引用。

这些时长按实际运行秒计算，是便于演示的视觉校准，不是水文或蒸发模拟。跳转昼夜不会把表面瞬间烘干；暂停菜单冻结雨滴和湿润程度。演练保持既有天气规则。

## 简化范围

使用固定轻风，没有风场和阵风求解；雨水不沿屋檐流下，不积成可交互水洼。湿润按明确登记的室外材质槽处理，不是逐纹素求解雨水遮蔽。现有反射环境和地面法线决定反光细节，不把所有地面改成镜面。溅水采用有数量上限的实例池，不给每颗雨滴建立碰撞或独立Actor。

## 验证与回滚

`rain_polish`检查自然湿润、原纹理保留、斜向遮雨、溅水表面、室内材质不变、暂停、雨后残余水分、干燥恢复及再次降雨。干燥恢复通过直接推进雨效模型181秒测试，前面的湿润阶段使用真实运行时间。
